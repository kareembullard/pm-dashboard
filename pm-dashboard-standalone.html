📋 PM Dashboard

Phase and task tracking, per-task time logging, progress analytics, and a project wiki — all in one page.

This is a portfolio demo. All data (the project, its phases, tasks and wiki pages) is fictional sample data, seeded on first load. Everything is editable — add/edit/delete phases, tasks and wiki pages, tick tasks off, and log time with the built-in timer. Edits save to your browser only (localStorage); nothing is ever sent to a server. Use Reset to restore the original demo seed.
